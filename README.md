
# Lumora ⚡
### Smarter Energy, Brighter Future.

Lumora is a web-based electricity consumption analytics dashboard designed to help users understand energy usage, estimate electricity bills, and explore consumption patterns.

## ✨ Features

- 📊 Electricity consumption visualization
- 💡 Energy usage breakdown
- 🧮 Electricity bill calculator
- 📈 Daily, weekly, and monthly chart views
- 🔍 Usage insights and energy-saving suggestions
- 📱 Responsive dashboard interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js

## 🌐 Live Demo

[Explore Lumora](https://rabby2027.github.io/Lumora/)

## 📌 Project Status

This is a portfolio project. The dashboard uses demonstration data and does not currently connect to live electricity meters or utility accounts.

## 🎯 Project Goal

To explore how web technologies and data visualization can make electricity consumption easier to understand and help users make informed energy decisions.
